# LLBC Translation Pipeline — Overview

A single-page overview of the Life Leadership Bible College video localization
pipeline (English → Spanish + Italian, with the teacher's cloned voice and
lip-synced footage).

**Live page:** https://brianpitre.github.io/llbc-pipeline-overview/

The page is a self-contained static HTML file (`index.html`) — no build step,
no external dependencies. Published via GitHub Pages.
